General overview of an HTML project

To build a website, you first need to know what to have on the site (text, titles, tables, the list goes on). This site will go over the basics to get you started with your first website!

General Overview of HTML Elements

Here are some common elements to get you started developing projects using HTML:
Element Name Element Description Example Usage
Headers <h1>, <h2>, <h3>, <h4>, <h5>, <h6>, Headers are used to label titles, subtitles, and other headers within your webiste <h1>Example Title</h1>
Paragraph <p> Paragraphs make it possible for developers to add descriptive text around the website they are developing! <p>This is an example of paragraph text. This is very common to see on any website you visit!</p>
table <table> Tables allow you to represent data visually on a site in a formatted way! You may assign table headers, rows, columns, and borders. This includes elements which are named similarly to the element's purpose. <table> <tr class="table-header"> <thead> <th> Table Header </th> </thead> </tr> <tr class="normal-row"> <td> Row data </td> </tr> </table>
